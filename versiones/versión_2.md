Temas de la segunda versión:
Vamos a inplmentar un modo multijugador competitivo.
Para este modo multiplayer la pantalla del telefono deberá dividirse en dos, para hacer esto el sistema debe rotar el telefono de manera horizontal.

Modelo de negocio: Skins y estatus.
Crearemos una nueva pantalla que se tratará de aspectos, vamos a crear decenas de diseños y tematicas transformando las gemas y el paisaje en animales marinos, por ejemplo. Pueden variar los diseños, también puede hacer una temática espacial.
El punto es que esta pantalla de tienda debe almacenar todos los diseños que tendremos para vender, deberemos usar el sistema de google billing para cada skin y poder desbloquearlas. (No desbloqueargemas, gemas ya están desbloqueadas desde el inicio).
Tendremos diferentes modelos de skins, desde las más económicas (sacarlas rápido al mercado) hasta las más caras (tendrán un mes de desarrollo por ejemplo).
Vamos a usar nuestros cristales como monedas para comprar skins, le damos doble utilidad a estos cristales.
Tipos de diseños:
Comunes: Un día de trabajo | Ícono: Círculo de perla | Valor = 100 cristales
Especiales: Una semana de trabajo | Ícono: Triángulo de esmeralda | Valor = 600 cristales
Épicas: Dos semanas de trabajo | Ícono: Pentágono de topacio | Valor = 1,000 cristales
Legendarias: Un mes de trabajo | Ícono: Hexágono de zafiro | Valor = 2,500 cristales
Míticas: Dos meses de trabajo | Ícono: Octágono de rubí | Valor = 5,000 cristales
Exquisitas: Tres meses de trabajo | Ícono: Decágono de diamante | Valor = 7,500 cristales
