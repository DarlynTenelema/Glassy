Esta versión de mi juego conserva gran parte de las características originales, pero con importantes modificaciones para adaptarla a la plataforma de TikTok.

La lógica de rebote y merge son las mismas.
Son las mismas gemas:
- Esmeralda
- Amatista
- Topacio
- Peridoto
- Zafiro
- Rubí
- Diamante
Pero también integramos nuevos elementos.
- Cuarzo: Se puede fusionar pero no genera una nueva gema y solo desaparecen dando 20 puntos.
- Piedra: No se puede fusionar, solo se elimina si se fusiona alguna otra gema cerca de esta y da 30 puntos.

También tenemos 2 dinámicas extras:
Combos: Al fusionar varias veces una misma gema se genera un combo que da más puntos.
Micro-misiones: Son tareas que se generan mientras el usuario está jugando al completarlas se otorgan recompensas. A diferencia de la versión para móvil, si el creador de contenido no completa la misión a tiempo se produce un game over.
Vamos a modificar un poco el sistema de micro-misiones de esta versión para que:
Tengo 1 minuto(60 segundos) de tiempo para completar la misión.
Configuramos el sistema para que dé misiones más dinámicas;
- Fusiona X gema (Límite de 5 y no incluye al cuarzo, diamante o piedra, si es una gema grande como el rubí o el zafiro el límite es de 2)
- Llega a un combo de X5 con X gema (Menos el cuarzo, diamante o la piedra)
- Reune X puntos. (Límite de 300)
- Elimina todas las X gema del juego durante X tiempo (Límite de 30 segundos y no incluye al cuarzo, diamante o piedra)
- Manten X cantidad de X gema durante X tiempo (Configuración hard: 10 para las gemas más cercanas como esmeralda o amatista, 6 para gemas como el topacio hasta peridoto, 3 para gemas como el zafiro hasta rubí, no incluye al cuarzo, diamante o piedra, límite de tiempo de 40 segundos)
